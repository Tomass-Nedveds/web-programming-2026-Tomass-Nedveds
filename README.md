# CampusFlow — pāreja no CSS uz Tailwind CSS

Šajā mapē atrodas sākotnējā **CampusFlow** tīmekļa vietnes versija, kas izveidota, izmantojot tradicionālo CSS.

Tā jāizmanto kā sākuma un atsauces versija 1. nedēļas praktiskajam Tailwind CSS uzdevumam.

## Faili

- `index.html` — sākotnējā HTML struktūra;
- `styles.css` — sākotnējais tradicionālais CSS;
- `app.js` — esošā JavaScript funkcionalitāte;
- `TASK.md` — praktiskā uzdevuma instrukcija;
- `AI_USAGE.md` — MI izmantošanas apraksta veidne;
- `REFLECTION.md` — individuālās refleksijas jautājumi.

Studentiem Visual Studio Code vidē jāizveido **Vite + Tailwind CSS** projekts un tajā jāpārveido dotās tīmekļa vietnes vizuālais noformējums.
